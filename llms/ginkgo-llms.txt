# Ginkgo Bioworks

> Ginkgo Bioworks is a synthetic biology company whose public developer surface is the Ginkgo AI Model API — an async, job-polling REST service for running inference on public and Ginkgo-proprietary biological foundation models (protein and DNA masked language models and embedding models). Authenticated with an x-api-key header; an official Python client is published on PyPI. Generated by the API Evangelist enrichment pipeline from the provider's public repos, package registries, and docs.

## APIs

- [Ginkgo AI Model API (docs)](https://ginkgobioworks.github.io/ginkgo-ai-client/): Run masked-inference and mean-embedding transforms on protein/DNA sequences against Ginkgo AI models.
- Base URL: https://api.ginkgobioworks.ai/v1
- Submit (single): POST https://api.ginkgobioworks.ai/v1/transforms/run
- Submit (batch): POST https://api.ginkgobioworks.ai/v1/batches/transforms/run
- Result: poll the job result URL returned by the submit call until status == COMPLETE.

## Models

- esm2-650M, esm2-3B (protein)
- ginkgo-aa0-650M (protein)
- ginkgo-maskedlm-3utr-v1 (DNA)
- lcdna (DNA-IUPAC), abdiffusion (protein), mrna-foundation (DNA)
- Promoter-0, LCDNA and others listed as coming soon.

## Authentication

- API key in the `x-api-key` request header.
- Keys and usage credits are issued from https://models.ginkgobioworks.ai/
- The Python client reads GINKGOAI_API_KEY from the environment.
